# BoxuGo — Locker Management REST API

## Deskripsi

BoxuGo adalah aplikasi backend untuk pengelolaan locker sebagai tempat penyimpanan barang sementara. Sistem mengelola pelanggan, ketersediaan locker, transaksi penitipan, kode pengambilan, tarif, dan denda keterlambatan.

## Teknologi

- Java
- Spring Boot
- Spring Data JPA
- PostgreSQL
- REST API
- Swagger UI
- Postman
- Docker

## Fitur Utama

- Menampilkan locker yang tersedia.
- Mengelola data pelanggan.
- Membuat transaksi penitipan barang.
- Menghitung tarif berdasarkan ukuran locker dan durasi.
- Menghasilkan kode pengambilan barang.
- Memproses pengambilan barang dan denda keterlambatan.
- Menyimpan data transaksi ke PostgreSQL.
